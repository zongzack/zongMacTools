工具来源

为什么是 zongMacTools

有些好用的体验已在别的桌面系统里证明过自己，但需要重新做成符合 macOS 使用方式的工具；也有些 Mac 日常操作里的效率空白，值得被直接补上。zongMacTools 沿着这两条路径持续构建。

体验迁移工具

已在别处验证，为 Mac 重做

从其他桌面系统中被反复验证的交互出发，按照 macOS 的习惯、系统边界和公开 API 重新实现。迁移的是体验，不是界面复刻。

macOS 增益工具

直接补齐 Mac 的效率空白

不以其他平台为起点，从 Mac 日常操作里真实遇到的别扭细节出发，给出顺手、克制、像系统自带一样的答案。

首个工具

Dock Window Quick Look（Dock 窗口速览）

首个已实现工具

停在 Dock 上正在运行的应用图标，查看它当前可枚举的窗口；选择预览卡片切换窗口，或在卡片上右键使用当前可用的窗口操作。

步骤 1 / 4

停在 Dock

指针停在正在运行的 Dock 应用图标上。

  • 悬停 Dock 图标，预览当前可枚举窗口（静态缩略图，非实时视频）
  • 选择预览卡片，切换并激活目标窗口
  • 在卡片上右键，使用当前可用的窗口操作

不承诺实时预览、跨 Space 窗口、恢复最小化窗口或多显示器行为；这些边界以 GitHub 发行详情为准。
