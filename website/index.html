工具来源

为什么是 zongMacTools

有些好用的体验已在别处证明自己，但需要重新做成符合 macOS 使用方式的工具；也有些效率空白，值得直接为 Mac 补上。

01

体验迁移路径

体验迁移工具

从其他桌面系统中被反复验证的交互能力出发，按 macOS 的使用习惯、系统限制和公开 API 重新实现，而不是复制原有界面。

02

macOS 效率空白

macOS 增益工具

不以别处的功能为起点，直接改善 Mac 日常操作中值得被补齐的细节，让工具集合沿着真实工作流继续扩展。

首个已实现工具

Dock Window Quick Look（Dock 窗口速览）

停在 Dock，快速辨认正在运行应用的当前可枚举窗口，再把注意力准确带回要继续的任务。

首个已实现工具

悬停正在运行的 Dock 应用图标后查看预览卡片；选择卡片可切换目标窗口，右键卡片可使用当前可用的窗口操作。

  • 查看当前可枚举窗口预览
  • 选择卡片切换窗口
  • 右键使用可用窗口操作
