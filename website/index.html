两大核心功能

针对 macOS 用户最痛的两个场景，提供原生级体验。

Dock 窗口速览

鼠标悬停在 Dock 图标上，即刻弹出该应用所有窗口的缩略图。点击即可切换，告别 Cmd+Tab 的盲目翻找。

Finder 新建文件

在 Finder 空白处右键，直接新建 TXT、MD、JSON 等常用文件。支持自定义模板，让「新建文件」像 Windows 一样自然。

从 Windows 到 Mac，无缝过渡

你怀念的并不是 Windows，而是那些被 macOS 遗忘的高效习惯。

Windows → macOS

任务栏窗口预览 → Dock 悬停速览

Windows 任务栏悬停即可预览窗口，macOS 默认只能看到应用名。zongMacTools 把缩略图带回 Dock。

Windows → macOS

右键新建文件 → Finder 右键新建

Windows 资源管理器右键就能新建文件，macOS 需要打开终端或第三方编辑器。现在 Finder 也能一键新建。

更多细节，同样顺手

每一处设计都为了让 macOS 用起来更自在。

卡片式窗口预览

每个窗口以卡片呈现，清晰可辨，点击直达目标窗口。

原生级安全

需要辅助功能权限，但绝不收集任何数据，开源可审计。

常见问题

安装时提示「无法打开，因为无法验证开发者」怎么办？

首次安装未公证的 App 时，macOS 会拦截。请在「系统设置 → 隐私与安全性」中找到 zongMacTools，点击「仍要打开」。或者打开终端执行：xattr -dr com.apple.quarantine /Applications/zongMacTools.app

需要哪些系统权限？

仅需要「辅助功能」权限以监听 Dock 悬停事件和窗口信息。不访问网络、不读取文件内容、不上传任何数据。

支持 Intel Mac 吗？

目前主要针对 Apple Silicon（M1/M2/M3/M4）优化。Intel 版本尚在评估中，欢迎到 GitHub 提交需求。

如何卸载？

将 zongMacTools.app 拖入废纸篓即可。配置项存储在 ~/Library/Preferences/，如需要彻底清理可一并删除相关 plist 文件。
