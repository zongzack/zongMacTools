# zongMacTools 文档

`zongMacTools` 是一组 macOS 桌面效率工具，面向希望保留 Windows 常用操作习惯的 Mac 用户。项目目前包含两项独立功能：Dock 窗口速览和 Finder 右键扩展。

| 功能 | 用途 | 详细文档 |
| --- | --- | --- |
| Dock 窗口速览 | 悬停 Dock 中正在运行的应用，查看并操作其窗口。 | [Dock 窗口速览](dock/README.md) |
| Finder 右键扩展 | 在 Finder 目录或桌面空白处快速创建内置或自定义模板文件。 | [Finder 右键扩展](finder/README.md) |

## 共同要求

- 需要 macOS 14 或更新版本。
- Dock 窗口速览需要辅助功能与屏幕录制权限。
- Finder 右键扩展需要在系统设置中启用 Finder Sync 扩展。
- 应用的安装、源码构建、打包和开发命令见仓库根目录的 `README.md`。

## 文档使用方式

先根据要使用的功能进入对应说明。两份详细文档分别介绍功能范围、启用步骤、日常操作、可配置选项、数据保存位置、限制和常见排查方向；它们不包含发布历史或过期验收记录。
