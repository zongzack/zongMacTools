# Finder 右键扩展

Finder 右键扩展通过 Finder Sync 在 Finder 普通目录或桌面空白处提供“新建文件 / New File”菜单。它可快速创建常用空白文件，也可将自己的文件导入为模板。

返回 [文档总览](../README.md)。

## 首次启用

1. 将 `zongMacTools.app` 放在固定位置，建议使用 `/Applications/zongMacTools.app`。
2. 启动应用，并从菜单栏打开设置窗口。
3. 进入“右键扩展 / Right-click Extension”。
4. 点击“管理 Finder 扩展 / Manage Finder Extension”。
5. 在“系统设置 > 隐私与安全性 > 扩展 > Finder”中启用 `zongMacTools`。
6. 返回设置页面并确认扩展状态为已启用。

Finder Sync 是独立于主应用的系统扩展。主应用退出后，Finder 扩展仍可读取最后保存的配置并创建文件；替换、重新签名或移动应用后，macOS 可能要求再次启用扩展。

### 启用后的检查方法

1. 在设置页面确认状态显示为已启用。
2. 打开一个可写的本地文件夹，点击空白区域以取消任何文件选择。
3. 在空白处右键，确认出现“新建文件 / New File”父级菜单。
4. 展开父级菜单，确认至少有一个已启用的格式。

如果状态变化没有立即反映，关闭并重新打开 Finder 背景菜单；不需要使用 `pluginkit`、强制重启 Finder 或关闭系统安全功能。

## 菜单出现的位置

菜单只会出现在可写入的本地普通目录或桌面背景的右键菜单中。扩展会避免在下列位置显示菜单：

- 已选中文件、文件夹或多个项目时。
- Finder 侧边栏、工具栏和项目右键菜单。
- 最近使用、搜索结果等虚拟位置。
- 不存在、不可写、非文件 URL 或系统不支持的目录。

这样可以避免在不明确的目标位置创建文件，或覆盖用户当前选中的项目。

### 菜单判断示例

| 你右键的位置 | 是否显示菜单 | 原因 |
| --- | --- | --- |
| 可写本地文件夹的空白处 | 显示 | 目标目录明确，允许创建新文件。 |
| 桌面空白处 | 显示 | 桌面被视为可写容器背景。 |
| 已选中的文件或文件夹 | 不显示 | 避免把创建操作误解为对选中项目的操作。 |
| Finder 侧边栏或工具栏 | 不显示 | 这些位置不是文件创建目标目录。 |
| 最近使用或搜索结果 | 不显示 | 结果可能来自多个来源，缺少稳定的目标目录。 |
| 只读目录、垃圾篓或不受支持位置 | 隐藏或创建失败并提示 | 扩展不会绕过文件系统权限或系统限制。 |

## 内置格式

默认目录包含以下六种格式，均可单独启用或停用。

| 菜单项 | 扩展名 | 创建内容 |
| --- | --- | --- |
| TXT | `.txt` | 零字节文本文件。 |
| Markdown | `.md` | 零字节 Markdown 文件。 |
| JSON | `.json` | UTF-8 编码的 `{}` 与换行符。 |
| Word | `.docx` | 内置空白 OOXML Word 模板。 |
| Excel | `.xlsx` | 内置且包含 `Sheet1` 的空白工作簿模板。 |
| PowerPoint | `.pptx` | 内置且包含一张空白幻灯片的演示文稿模板。 |

创建 Office 文件不要求安装 WPS 或 Microsoft Office；这些应用只在打开、编辑和保存文档时需要。内置格式的文件后缀固定，避免菜单名称与实际文件类型不一致。

### 菜单名称与语言

内置格式在简体中文环境中使用 `TXT`、`Markdown`、`JSON`、`Word`、`Excel`、`PowerPoint` 等简洁名称；在其他语言环境中会使用对应的 `… File` 菜单名称。默认创建文件名会相应采用 `新建文稿` 或 `New Document`。

自定义模板始终使用你设置的显示名称。修改显示名称只影响菜单文字和新文件名词干，不会修改已经创建的文件。

## 创建文件的行为

- 内置项目默认以 `新建文稿.ext` 或 `New Document.ext` 命名，取决于系统语言；自定义模板使用其显示名称作为文件名词干。
- 如果同名文件已存在，扩展依次尝试 ` 2`、` 3` 等后缀，最多尝试 10,000 个候选名称，不覆盖既有文件。
- 写入使用临时文件和独占重命名，尽量避免在重名竞争、符号链接或目录状态变化时留下半成品。
- 创建成功后，Finder 会选中新文件。
- 目标目录不可写、模板缺失、文件名全部占用或写入失败时，扩展显示一次错误说明，不修改已有文件。

### 为什么不会覆盖已有文件

扩展不会先“检查存在后再普通写入”，因为另一个进程可能在两步之间创建同名文件。它会在目标目录内创建一个仅当前操作使用的临时文件、写入并同步内容，再使用独占重命名提交最终文件名。如果最终名称刚被其他程序占用，会改用下一个编号；如果目录状态发生异常变化，临时文件会被清理。

这项机制同样避免把创建内容写到符号链接指向的意外位置。它不等同于替代文件系统权限：没有写权限、磁盘已满或系统文件提供程序拒绝写入时，创建仍会失败并显示原因。

## 配置内置格式

在“右键扩展”设置页中，每个项目都可以：

- 使用开关启用或停用；全部关闭后，Finder 中的父级“新建文件”菜单也会隐藏。
- 通过拖拽调整排序；下次打开 Finder 菜单时立即使用新顺序。
- 双击显示名称进行修改；内置格式仍保留其固定后缀。
- 使用“恢复默认”恢复六种内置格式的名称、顺序和启用状态，同时清除自定义模板。

### 修改内置项目的步骤

1. 打开设置中的“右键扩展”。
2. 使用右侧开关控制某种格式是否出现在 Finder 菜单中。
3. 拖动行左侧的排序控制，调整它在菜单中的位置。
4. 双击名称，输入新的显示名称后按 Return，或点击到其他位置完成保存。
5. 在 Finder 的目录空白处重新打开右键菜单，确认菜单已刷新。

内置格式的扩展名不可改：例如 Word 始终创建 `.docx`，JSON 始终创建 `.json`。这能保证内置内容、文件图标和实际后缀一致。

## 自定义模板

点击“导入模板”可一次选择多个普通文件。每个成功导入的文件会复制到扩展自己的模板目录，并成为可排序、可开关的自定义菜单项。

- 自定义模板的显示名称和文件后缀都可编辑；后缀会标准化为小写且不能包含路径分隔符、空白或空值。
- 目录、符号链接、无后缀文件、不可读取项目或名称非法的项目不会导入；同一批导入中的其他有效文件仍会保留。
- 删除自定义项时会要求确认；确认后删除该项及其私有模板副本。
- “恢复默认”会清除所有自定义项和由本功能创建的模板副本，不会删除同目录中的无关文件。

### 导入与管理模板的步骤

1. 在“右键扩展”页面点击“导入模板”，选择一个或多个本地普通文件。
2. 导入后检查列表：成功项会立即出现，失败项会汇总显示文件名和原因。
3. 需要时双击名称或后缀修改自定义项；内置项的后缀保持锁定。
4. 使用拖拽改变模板在菜单中的位置，或关闭开关暂时隐藏模板。
5. 删除模板时点击垃圾桶图标并确认。取消确认不会删除条目或副本。
6. 需要一次性清理所有自定义内容时，使用“恢复默认”并确认。

导入创建的是副本，而不是原文件的实时链接。之后修改原文件不会改变已经导入的模板；需要更新内容时，请删除旧模板后重新导入新版文件。

## 数据保存位置

配置和模板都保存在当前真实用户的 Application Support 目录，而不是 App Bundle：

```text
~/Library/Application Support/com.zong.zongMacTools/FinderNewFile/catalog.json
~/Library/Application Support/com.zong.zongMacTools/FinderNewFile/Templates/
```

`catalog.json` 保存菜单项、顺序、启用状态和模板引用；`Templates/` 保存导入文件的私有副本。卸载或替换 App 不会自动删除这些用户数据。

### 数据生命周期

- 变更格式名称、顺序、开关或模板后，目录会保存为新的 catalog 配置。
- Finder 扩展在下次构建菜单时读取该配置，因此通常无需重启主 App。
- 删除单个自定义项会删除该项拥有的模板副本；取消操作则保留副本。
- “恢复默认”会恢复内置目录，并只删除由本功能管理的 `custom.` 模板副本。
- 如果以后彻底卸载并且不再需要模板，可由用户自行删除上述 `FinderNewFile` 目录；这不会影响应用包以外的其他数据。

## 限制与排查

| 现象 | 优先检查 |
| --- | --- |
| Finder 中没有“新建文件” | Finder 扩展是否已在系统设置启用；菜单是否在目录或桌面空白处打开；是否至少启用了一个格式。 |
| 菜单没有某个格式 | 对应格式是否被关闭，或是否被恢复默认/排序到菜单下方。 |
| 无法创建文件 | 当前目录是否可写；是否为虚拟位置、云盘或文件提供程序目录；系统是否显示了权限或错误提示。 |
| 自定义模板无法创建 | 模板副本是否仍存在；`catalog.json` 中的引用是否完整；原始文件修改不会自动同步到已导入副本。 |
| Office 文件打开出现兼容性问题 | 使用本机 WPS 或 Microsoft Office 完成最小编辑和保存验证；不同 Office 实现的兼容性由目标应用决定。 |
| 修改设置后菜单没有变化 | 关闭并重新打开 Finder 背景菜单；确认操作已保存，并检查扩展仍处于启用状态。 |
| 全部格式都不见了 | 检查每项开关；全部关闭时父级“新建文件”菜单会隐藏。可使用“恢复默认”重新启用内置格式。 |
| 导入模板失败 | 确认选择的是可读取的普通文件、有合法后缀且名称不为空；目录、符号链接和无后缀项目不会导入。 |
