# Dock 窗口速览

Dock 窗口速览会在鼠标停留在 Dock 中正在运行的应用图标上时，显示该应用可用窗口的静态缩略图。它适合在多个窗口之间快速识别和切换，而无需逐个激活应用。

返回 [文档总览](../README.md)。

## 功能范围

- 监听 Dock 中正在运行的应用图标，并在悬停延迟结束后显示预览面板。
- 枚举当前可交互环境中符合系统条件的普通窗口，展示窗口标题、应用图标和静态缩略图。
- 点击预览卡片可激活对应窗口。
- 右键预览卡片可执行激活窗口、隐藏应用、关闭窗口或最小化窗口等操作；不可用操作会保持不可用状态，不会强行调用私有接口。
- 支持在预览卡片上显示静态桌面窗口速览效果；该效果可独立关闭，不影响普通窗口缩略图。
- 支持中英文界面、浅色/深色外观和“减少动态效果”系统偏好。

预览是按需生成的静态图像，不录制系统声音，也不会持续录制屏幕。窗口列表和缩略图的可用性由 macOS 权限、窗口类型、当前空间和系统捕获规则共同决定。

## 预览面板中有什么

每张窗口卡片对应一个系统可识别的目标窗口。卡片会尽可能显示：

- 所属应用的图标，用于在标题相近时区分来源。
- 窗口标题；应用未提供标题时，系统可能显示为空或使用可用的替代信息。
- 该窗口的静态缩略图；缩略图尚在准备时显示加载状态，无法获取时显示占位状态。
- 可操作状态；例如某个应用不允许最小化时，“最小化窗口”不会被作为可执行操作提供。

卡片数量受到“最大卡片数”限制。窗口较多时，系统会优先在当前可用候选中构建面板；面板不会把其他 Space、最小化窗口或系统拒绝枚举的窗口伪装成可用窗口。

## 首次启用

1. 启动 `zongMacTools.app`。
2. 打开菜单栏图标中的设置窗口。
3. 在 macOS“系统设置 > 隐私与安全性”中授予应用“辅助功能”和“屏幕录制”权限。
4. 返回应用设置，确认 Dock 窗口速览已启用。
5. 将鼠标放在 Dock 中一个正在运行的应用图标上，等待预览面板出现。

辅助功能用于监听 Dock 交互和执行窗口操作；屏幕录制权限用于枚举窗口并生成静态缩略图。如果其中任一权限不可用，应用会静默抑制常规预览，而不是在每次悬停时重复弹窗。

### 权限状态的含义

| 权限或条件 | 对 Dock 窗口速览的影响 |
| --- | --- |
| 辅助功能已授权 | 可以监听 Dock 状态，并尝试激活、关闭或最小化支持的窗口。 |
| 辅助功能未授权 | 不启动常规 Dock 监听；窗口操作也不可用。 |
| 屏幕录制已授权 | 可以请求窗口列表与静态缩略图。 |
| 屏幕录制未授权 | 正常悬停预览被抑制，避免只显示不完整或误导性的面板。 |
| 目标应用没有符合条件的窗口 | 不显示可操作卡片。 |

授权后如仍无反应，可先完全退出并重新启动 `zongMacTools.app`，再在设置页确认状态。重新签名、移动或替换 App 后，macOS 有时会把它视为新的受信任对象，需要重新检查权限。

## 日常操作

### 打开与关闭预览

- 将鼠标悬停在 Dock 图标上，等待设置的延迟后显示预览。
- 从 Dock 图标移动到预览面板时，应用会保留面板，便于点击卡片。
- 按 `Esc`，或将鼠标移出 Dock 图标与预览面板的有效区域，可关闭面板。
- 快速掠过 Dock 图标、切换到其他候选应用或离开有效区域时，旧预览会取消或隐藏，避免残留面板。

### 切换或操作窗口

- 左键点击卡片：激活对应窗口，然后隐藏预览面板。
- 右键点击卡片：打开窗口操作菜单；可用操作包括激活、隐藏所属应用、关闭窗口与最小化窗口。
- 关闭和最小化依赖 macOS 辅助功能所暴露的能力。目标应用要求保存文件、拒绝关闭或不支持某个动作时，仍由目标应用和系统决定结果。

右键菜单中的操作不会绕过应用自身的安全规则。例如关闭有未保存内容的文稿时，是否保存、取消或继续关闭仍由原应用的确认界面处理；本工具不额外弹出第二个确认框。

### 从 Dock 移动到预览面板

预览不会把“鼠标离开 Dock”简单等同于“用户不再需要面板”。当指针正从 Dock 图标向面板移动时，应用会保留一条过渡区域；指针进入面板后，卡片保持可交互。反之，快速掠过 Dock、移动到相邻图标或离开面板与过渡区域时，会优先取消旧任务，避免显示错误应用的窗口。

如果你经常因为移动距离较大而提前关闭面板，使用“宽松”保留范围；如果面板经常在移动到相邻 Dock 图标时停留过久，使用“紧凑”保留范围。

### 静态桌面窗口速览

“静态桌面窗口速览”是普通窗口缩略图之外的视觉辅助：当某张符合条件的卡片进入速览状态时，应用可在原窗口框架中显示一帧静态桌面镜像。它不是实时视频、远程桌面或窗口录制，也不会接收鼠标事件。

- 关闭该开关后，Dock 悬停、窗口卡片和窗口操作仍然可用。
- 当前窗口被销毁、应用退出、鼠标离开或预览会话结束时，镜像会一并关闭。
- 无法捕获的窗口不会强行显示镜像。

## 设置项

在设置窗口的 Dock 窗口速览页面可以调整下列选项。

| 设置 | 可选值或行为 | 默认值 |
| --- | --- | --- |
| 启用 Dock 窗口速览 | 总开关；关闭后不再响应 Dock 悬停。 | 开启 |
| 静态桌面窗口速览 | 单独控制预览卡片的桌面窗口速览效果。 | 开启 |
| 悬停延迟 | 150、250 或 400 毫秒。 | 250 毫秒 |
| 面板保留范围 | 紧凑、标准、宽松；控制从 Dock 移向面板时允许的容差范围。 | 标准 |
| 最大卡片数 | 3、5、8 或 12 张。 | 8 张 |
| 排除应用 | 指定应用不触发 Dock 预览，可随时移除或清空。 | 无 |
| 显示语言 | 简体中文或 English。 | English |

排除规则按应用的 bundle identifier 保存。设置页可将当前目标应用加入排除列表，也可通过应用选择器手动加入其他应用；不会把 `zongMacTools` 自身加入列表。

### 建议的设置组合

| 使用习惯 | 建议 |
| --- | --- |
| 想快速掠过 Dock，仅在刻意停留时预览 | 400 毫秒延迟、紧凑保留范围。 |
| 经常在窗口之间来回切换 | 150 或 250 毫秒延迟、标准保留范围、8 张卡片。 |
| 使用触控板且容易提前移出面板 | 标准或宽松保留范围。 |
| 多窗口应用很多 | 12 张卡片；如信息过多，再减少到 5 或 8 张。 |
| 不希望会议、录屏或敏感应用出现缩略图 | 将对应应用加入排除列表，或临时关闭总开关。 |

设置会保存到本机用户偏好中，并在设置变更后通知相关预览流程；不需要重新打包应用。权限、窗口可见性和系统空间状态仍由 macOS 即时决定。

## 预览生命周期

一次正常的预览交互通常经历以下过程：

1. Dock 的辅助功能状态变化提供一个候选应用。
2. 应用确认鼠标仍在该 Dock 图标上，并等待设定的悬停延迟。
3. 延迟结束后再次确认候选、鼠标位置、开关、排除列表和权限，避免使用已过期的悬停事件。
4. 查询可用窗口，创建卡片并尝试填充静态缩略图。
5. 用户点击、执行右键操作、离开有效区域、切换到另一个 Dock 图标或目标应用终止时，面板和关联的桌面速览按当前状态关闭。

这些重复确认是有意设计：Dock 的选中状态可能在鼠标已离开后短暂保留，不能单独作为显示预览的依据。

## 窗口与权限限制

- 只显示系统允许枚举和捕获的窗口；最小化、不可见、特殊类型或其他 Space 中的窗口可能不显示。
- 全屏 Space、Dock 自动隐藏、Dock 位于屏幕左右侧等环境会由系统窗口几何和可见屏幕区域决定面板位置。
- 多显示器场景尚未完成完整验证。
- Dock 重启、目标窗口销毁、应用退出或权限状态变化时，当前预览会安全地停止并在后续交互中重新建立监听。
- 不使用 CoreDock 或其他私有 API；系统或应用不提供某种窗口能力时，该能力会降级而不是模拟执行。

## 隐私与数据边界

- 缩略图只用于当前本机的预览会话，不上传到网络，也不由应用持续保存为文件。
- 应用不会录制系统声音，不提供持续屏幕录像功能。
- 诊断或系统日志仅在用户主动导出诊断信息时才可能包含本机应用名称、窗口标题、bundle identifier 或环境信息；分享前请自行检查导出内容。
- 排除列表是最适合保护不希望出现预览的应用的方式；关闭窗口速览总开关可停止所有 Dock 悬停预览。

## 排查

| 现象 | 优先检查 |
| --- | --- |
| 悬停后没有面板 | 应用是否正在运行、Dock 窗口速览总开关、辅助功能和屏幕录制权限。 |
| 有面板但没有缩略图 | 屏幕录制权限、目标窗口是否可捕获、窗口是否最小化或位于其他 Space。 |
| 某个应用从不触发 | 是否已在排除列表；该应用是否有可枚举的普通窗口。 |
| 无法关闭或最小化窗口 | 目标应用是否通过辅助功能暴露相应操作；保存确认或权限提示是否仍在等待处理。 |
| 面板过早消失或停留太久 | 调整“面板保留范围”和悬停延迟。 |
| 面板显示的不是刚才悬停的应用 | 先离开 Dock 和面板区域，再重新悬停；若持续出现，检查 Dock 是否刚重启或目标应用窗口是否正在频繁变化。 |
| 静态桌面窗口速览未出现 | 检查该开关、屏幕录制权限和目标窗口是否可捕获；关闭该效果不会影响普通预览。 |
